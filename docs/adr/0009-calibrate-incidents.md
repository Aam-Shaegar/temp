# Калибровка порогов по журналу инцидентов

Статус — реализовано для кандидатов v4.

Калибровка порога проверяет работу журнала Go на целых отдельно размеченных записях. Сопоставление с разметкой выполняет общий оценщик. Сохраняются переходы между режимами, пропуски наблюдения, слияние, ошибка начала и ошибка конца. Служебный бинарник Go находится в Docker-образе тренера. Сервинг использует существующий API прогнозов и артефакт с зафиксированной политикой v4.

Календарь выбирает режим калибровки и исключён из входа обучаемого сетевого детектора. Режим без подтверждённых штатных и положительных примеров получает явный статус недоступности. У HTTP-правила сохраняется собственное наблюдаемое состояние. Артефакты прежних политик остаются совместимыми. На v4 прежний порог `1.0` также даёт явную недоступность сетевого прогноза.

Кандидат сравнивается по частоте ложных инцидентов на оценённой экспозиции и качеству границ. Штатное покрытие и наличие известных сетевых эпизодов публикуются по режимам. Отказы типизации измеряются по свидетельству HTTP и по сетевым событиям неизвестного типа. Успех в одной категории не закрывает критерий другой. Требуемый объём штатной экспозиции и независимость приёмки задаются протоколом проверки.
